# implement-graphite-stack

We are going to implement this change in multiple PRs using a graphite stack. In your plan, break the implementation into multiple PRs and specify which changes will be included in each PR. Once the plan is given approval, please make the changes for each pr one at a time, and let me know when you're done with each. I.e., after you have made the changes for PR #1, stage the changes and then come back to me, and I will create the pr manually and then let you know when to continue with changes for PR #2. Do NOT commit changes or create PRs, I will handle this manually.
